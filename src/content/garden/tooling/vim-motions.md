The motions that actually changed how I edit, as opposed to the ones I learned for party tricks:

- `ci(` / `ci"` — change inside delimiters. The gateway drug.
- `.` — repeat. The whole editing model clicks when you start composing for repeatability.
- `%` — jump between matching pairs. Free with no config.
- `g;` — jump to last change. Criminally under-taught.

Everything below is pinned via [[nix-flakes]], so my neovim config is identical on every machine — which is the only reason muscle memory like this survives.
