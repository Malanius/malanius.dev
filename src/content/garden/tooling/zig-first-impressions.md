Two weekends in. Raw notes, likely wrong:

comptime feels like the thing C macros always wanted to be. Error unions make the happy path noisy but the failure path honest. The allocator-passing convention is annoying for exactly as long as it takes to debug your first leak, and then it's brilliant.

Verdict so far: I don't need it for anything, which is historically how all my favorite tools started.
